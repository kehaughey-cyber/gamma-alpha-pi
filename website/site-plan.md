## Navigation Structure

The rebuilt site has five pages in the navigation bar. In this order:

Home

About

The Journey

Join Us

Books, Coin and Merch

The Contact page remains accessible via the footer only. It is not a primary navigation item. The Program List page is renamed The Journey and resequenced. All other pages remain on the existing Wix infrastructure.

## Design Principles for the Rebuild

Dark background. Gold text for headlines and emphasis. Clean white body text on dark sections. The site should feel weighted, serious, and masculine -- not corporate.

Minimal navigation. One path. The man should never wonder where to go next.

No jargon. No program language. The Forge, the Mine, the Drafting Room -- these are internal system names. The public website uses plain, direct language.

Every page ends with one clear next step. Never leave a man without direction.

Mobile first. Most men will find this on a phone.
