# website — the forward-facing door

The public site is the first thing a man meets before any brother does. This lane holds
what the site must *say* and *do* — the spec, the copy, the flow from stranger to
intake — not the site's code (that is the collaborator's build) and not the marketing
funnel machinery (that stays in the quarry until a specific piece is needed). This lane
serves **Step 4: cross the minimum public-launch threshold.**

## Current state
The storefront is **already live** on Wix at `gammaalphapi.com`:
Home / About / Join Us / Books, Coin and Merch / Contact / Program List, plus a Discord
and a PayPal donation. The Wix editor backend is behind Kevin's login — a **manual seam**;
Kevin drives it or grants access when we work it.

So the site exists. The open question is not "build a site" — it is **does the live site
say the true thing and route a man to the walk.** That gap is what this lane closes.

## What belongs here (curate from the quarry, converted to Markdown)
- **Site spec / rebuild intent** — `GAP/GAP_Website_Rebuild_Instructions.docx`, `website and app.docx`.
- **Program of work** — `WBS for creating a global fraternity.docx`.
- **Launch copy** — mine specific pieces from `Marketing/` (founder's story, the
  problem GAP addresses, objections) as the site needs them. Do **not** import the
  whole marketing folder; it is archive.
- **The intake handoff** — where the public site ends and `operations/` intake begins.
  This seam is the whole point: the door has to open onto the walk.

## Non-negotiables
- **House voice on the public page too** (`system/voice.md`): orient, do not flatter or
  sell. A funnel that flatters betrays the thing before a man is even in.
- The site's job is to get the right man to **start** (the first of the four problems),
  and to be honest enough that the wrong man self-selects out.

## Build order
Reconcile what the live site says against the current corpus and system truth first
(copy audit). A rebuild, if it happens, is downstream of knowing what it must say.
