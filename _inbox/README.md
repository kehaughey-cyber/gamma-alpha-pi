# _inbox — raw capture

Drop useful raw material here: pasted chat threads, exports from other projects,
half-formed ideation, voice notes transcribed, anything worth keeping but not yet
shaped. One file per source is fine. Messy is fine. Name them so you can tell what
they are (`chat-companion-architecture-2026-06.md`, `ideation-coin-symbolism.md`).

Nothing in here is canonical. It gets refined *out* of here into `system/`,
`companion/`, `operations/`, or the corpus, and then the raw copy can stay as a
record or be deleted. The rule: **`_inbox/` is raw, everything else is curated.**

## Migrating chats and old projects
- **On-disk material** (the old `Fraternity` folder: `ideation/`, `GAP/`,
  `Research/`, `Marketing/`): does not need to pass through here. It can be curated
  straight into the structured folders. Ask and it gets pulled in and converted.
- **Web chats** (Claude projects, other assistants): export or copy the useful
  parts into a file here. They cannot be read directly from disk, so capture is
  manual, but refinement is not.
